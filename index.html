저장 권한 (GitHub 토큰)

설정은 GitHub의 alert-settings.json에 저장되고, 감시 프로그램이 다음 조회(10~20분 안)부터 반영해요. 토큰은 이 기기 브라우저에만 저장돼요.

토큰 만드는 법
  1. github.com → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → TennisCourt
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate token → 복사해서 위 칸에 붙여 넣기

요금과 예약 규칙은 2026-10-15에 각 운영처 안내 페이지와 공개 자료를 보고 정리했습니다. 이용 전 공식 사이트에서 다시 확인하세요.

소요시간은 노선 기준 추정치입니다. 정확한 경로는 각 카드의 길찾기 버튼으로 확인하세요. ‘위치 근사’ 표시가 있는 코트는 지도 핀이 실제 위치와 조금 다를 수 있습니다.
